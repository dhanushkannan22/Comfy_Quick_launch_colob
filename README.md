# 🎨 ComfyUI on Google Colab — Easy & Fast Setup

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/drive/1GhumtgMfKwKA_sNA9zz2yvMbc6EnH_9o#scrollTo=nNN9qHtVXzj_)

Run ComfyUI on Google Colab — no local GPU, no complicated install.
Just open the notebook, run the cells, and you're inside ComfyUI in minutes.

---

## ✅ What You Get

- ComfyUI running on free cloud GPU (Google Colab)
- Models managed via Google Drive — no re-downloading every session
- Clean, beginner-friendly setup
- Works even on a basic laptop or low-end PC

---

## 🚀 How to Use

1. Click the **Open in Colab** button above
2. Make sure your Google Drive is connected
3. Run each cell top to bottom
4. Open the generated link — ComfyUI loads in your browser

---

## 📦 Requirements

- Google account
- Google Colab (free tier works, Pro recommended for longer sessions)
- Google Drive with enough space for models (~10–20 GB)

---

## 💡 Tips

- Use **Colab Pro** if you need longer runtimes or faster GPU
- Save your workflows as `.json` and store them in Google Drive
- Don't close the Colab tab while ComfyUI is running
